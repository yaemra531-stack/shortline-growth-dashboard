# 21轮快速迭代成长仪表盘

「短线｜每日一个 AI 方法」的长期实践记录。通过 21 轮真实实践，逐步建立一套能在 **120 分钟内稳定生产一条高质量、约 1 分钟短视频**的系统。

[打开线上仪表盘](https://yaemra531-stack.github.io/shortline-growth-dashboard/)

## 网页目标

1. **记录成长。** 从 V1 起保存每轮的目标、实际验证、最大收获、卡点和复盘结论，回看关键进展、里程碑与认知升级。
2. **可视化进度。** 总览显示当前版本、完成轮数、完成率和阶段重点。六大方向分别呈现已验证的能力、当前卡点和下一步。路线图区分实践记录与后续计划。
3. **支持长期更新。** 在同一页面补充 V6–V21。后续可继续记录审美成长、风格成长、代表作品和发布结果。

## 页面结构

| 模块 | 内容 |
| --- | --- |
| 顶部总览 | 当前轮次、目标、进度、当前瓶颈和 V5 的单批精选数据。点击轮次可查看对应记录。 |
| 成长时间线 | V1–V5 的目标、验证、收获、问题、状态与结论。后续轮次可查看计划。 |
| 六大方向 | 选题、写稿、配音、动画、音效、剪辑。 |
| 21轮路线图 | 七个阶段和各轮计划。展开阶段可查看任务。 |
| 关键认知升级 | 短样片、组件复用、四类内容来源、AI 初筛、候选回查和提示词归档。 |
| 里程碑 | 已发生的关键实验和突破。 |
| 成长档案 | 审美、风格、作品和发布反馈的预留模块。 |

## 内容来源与验证边界

- 初版以《短线｜21轮快速迭代 V21.5》为基线。V1–V5 复盘、六大方向、路线、认知升级、里程碑和 V5 的 24 → 23 → 5 来自对原文的提取和归纳。能力状态和每轮的「通过／继续验证／已调整」是页面对验证范围的简短标注。
- V6–V21 的任务来自原文路线图，执行结果显示为「待补充」。成长档案四个模块的条目暂为空。页面随数据文件渲染，后续从 Markdown 更新需要人工核对和录入。
- **5 / 21 和 23.8% 衡量的是轮次进度。** V5 只验证一批候选的汇总与初筛，完整耗时、正式选稿、传播效果与 120 分钟稳定出片能力仍待验证。

## 本地打开与后续维护

下载或克隆仓库，保持文件相对位置，双击 `index.html` 即可离线查看。无需安装依赖或启动服务。

- `index.html` 定义页面结构，`style.css` 管理版式，`script.js` 将 `data.js` 渲染为页面。
- 完成新一轮后，在 `data.js` 的 `reviews` 中新增对应编号。例如复制编号 5 的结构并新增编号 6，填写 `title`、`goal`、`verified`、`takeaway`、`issue`、`conclusion` 和 `status`。确认该轮实践结束后将 `completed` 设为 `true`。总览、时间线和路线图会据此更新。
- 按需更新最新一轮的 `focus`、实际耗时 `duration`，以及 `directions`、`insights` 和 `milestones`。更新过的路线任务放在 `phases` 对应轮次。新的成长记录可填入 `extensions` 对应模块的 `entries` 列表。
- 刷新本地页面检查后，将修改提交并推送到 `main`。GitHub Pages 会从 `main` 根目录更新网站。
